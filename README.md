## 真实评价里被夸的和被吐槽的

被夸得最多的是放大镜的精度和手感。Hi-Precision 模式在 Retina 屏上能选到每一个物理像素，靠提高鼠标灵敏度和放大倍率实现，普通像素密度的屏幕也能用。这套东西被很多人当成 Mac 上取色工具的原型，后面不少竞品都是照着它做的。

第二个被反复提到的是色彩准确性。从 Safari、Xcode 这类原生应用里取色时，它会按显示器的色彩配置自动转换成 sRGB，取到的 RGB 值和代码里写的一致。做设计交付的人对这点比较在意，颜色对不上会返工。

吐槽集中在几个地方。没有对比度检查器，竞品已经把 WCAG 2 和 APCA 做进去了，它还没有。没有调色板导入导出，只有收藏和历史。系统要求是 macOS 14.6 或更高，老系统装不上，这点在安装前确认一下。

买断不等于永久免费升级，这是最需要说清楚的一条。官网写的是 1.7 版本（包含 Apple Silicon 支持）对官网直购用户免费，这句话本身就暗示大版本以后可能另收费。店铺的购买须知也把责任划得很清楚：Lifetime、永久更新这类说法来自开发商，未来的更新、维护和政策变更由开发商负责，店铺只做转达，不承担补偿或退款。

转售渠道的售后边界也要有心理预期。授权码丢了，店铺建议先联系开发商，也可以找店铺协助；安装和注册的基础支持店铺会提供；退款基本别想。这是渠道属性决定的，不是这家店的问题。
